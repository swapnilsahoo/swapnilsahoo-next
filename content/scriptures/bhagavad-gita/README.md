# Bhagavad Gita source corpus

This directory contains the source-text layer used by the website reader. It is generated by
`scripts/import-bhagavad-gita.mjs`; do not hand-edit the chapter shards.

- Eighteen chapter pages are fetched from Sanskrit Wikisource under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); these adapted source-text shards are distributed under the same licence.
- Every page is pinned to an exact revision in `manifest.v1.json`.
- The importer keeps the metrical Sanskrit and separately tagged speaker rubric, removes wiki
  markup and numbering, and normalizes strings to Unicode NFC.
- The pinned Wikisource witness has 700 verses. The selected reader declares and adds the attested
  Arjuna question as 13.1, yielding 701 verses; the manifest records the comparison source.
- No translation, glossary, grammar, pronunciation, commentary, or audio is bundled in this corpus.

Regenerate from the latest source revisions:

```sh
node scripts/import-bhagavad-gita.mjs --write
```

Verify the committed files against their pinned historical revisions:

```sh
node scripts/import-bhagavad-gita.mjs --check
```

Local release validation does not require the network:

```sh
node scripts/check-scripture-corpora.mjs
```
