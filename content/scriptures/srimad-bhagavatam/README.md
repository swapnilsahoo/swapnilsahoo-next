# Śrīmad Bhāgavatam source corpus

This directory contains the source-text layer used by the website reader. It is generated by
`scripts/import-srimad-bhagavatam.mjs`; do not hand-edit the chapter shards.

- **Scope: Skandha 1 of 12 only.** The Bhāgavata Purāṇa runs to roughly 18,000 verses across
  twelve skandhas; this corpus is a complete, reproducible reading text of the first skandha
  (nineteen chapters, 807 verses in this pinned edition) — not the whole Purāṇa. Later skandhas
  can be added the same way in future work; nothing here claims otherwise.
- All nineteen chapter pages are fetched from Sanskrit Wikisource under
  [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); these adapted source-text
  shards are distributed under the same licence.
- Every chapter page is pinned to an exact revision in `manifest.v1.json`.
- The importer keeps only the metrical text inside each numbered `<poem>` block. It removes wiki
  markup, verse-number markers, and the closing chapter colophon ("iti śrīmadbhāgavate ...
  adhyāyaḥ"), which restates the chapter number rather than a verse. A bracketed meter label
  (e.g. Druta-vilambita, Anuṣṭubh) preceding a verse is captured as separate `meter` metadata
  instead of being left embedded in the verse text.
- Source verse numbers are preserved exactly as printed, in the source's own reading order, and
  are **not** silently renumbered, merged, or deduplicated. Two real quirks survive from this
  specific pinned edition: Chapter 3 has no verses numbered 11 or 32 (evidently merged into a
  neighbour at some point in transmission), and Chapter 13 prints two consecutive, textually
  distinct verses both numbered 40. Each verse's stable ID and global sequence come from its
  1-based position within the chapter (`sourceIndex`), not from the printed number, so these
  quirks never collide two verses onto one ID or silently drop one.
- Speaker attributions (e.g. "yudhiṣṭhira uvāca") are left embedded in the verse text as printed,
  unlike the Bhagavad Gītā corpus's separated `speaker` field — the Gītā's two-speaker structure
  follows one stereotyped short-line pattern; the Bhāgavatam's many speaker changes across a
  skandha do not follow a single reliable pattern to extract automatically without risking error.
- No translation, glossary, grammar, pronunciation, commentary, or audio is bundled in this corpus.

Regenerate from the latest source revisions:

```sh
node scripts/import-srimad-bhagavatam.mjs --write
```

Verify the committed files against their pinned historical revisions:

```sh
node scripts/import-srimad-bhagavatam.mjs --check
```

Local release validation does not require the network:

```sh
node scripts/check-scripture-corpora.mjs
```
